`# 🤖 AI-Powered Data Analysis Agent

An automated Python-based Data Analysis and Business Intelligence Agent that analyzes Excel and CSV datasets and generates useful business insights, KPIs, charts, recommendations, and professional PDF reports.

## 🚀 Features

- 📥 Excel and CSV file loading
- 🧹 Automatic data cleaning
- 🔍 Automatic dataset detection
- 📊 Automated KPI generation
- 💡 Business insights
- 🎯 Business recommendations
- 📈 Automatic data visualization
- 📄 Automated TXT reports
- 📑 Professional PDF reports
- 🤖 One-click data analysis

## 📊 Supported Analysis

### Sales Dataset
- Total Sales
- Average Sale
- Highest Sale
- Lowest Sale
- Total Orders
- Total Quantity
- Top Product
- Top Region
- Top Category
- Business Recommendations

### Employee Dataset
- Salary KPIs
- Department analysis
- Employee insights
- Employee charts
- Automated reporting

## 🛠️ Technologies

- Python
- Pandas
- Matplotlib
- ReportLab
- Excel
- CSV
- Jupyter Notebook

## 🔄 Workflow

Excel / CSV
→ Data Loading
→ Data Cleaning
→ Dataset Detection
→ KPI Analysis
→ Business Insights
→ Charts
→ Recommendations
→ PDF Report

## 📁 Project Output

The system can automatically generate:

- Sales reports
- Business insights
- Data visualization charts
- Professional PDF reports

## 🎯 Project Goal

The goal of this project is to automate common data analysis and business intelligence tasks so that users can upload a dataset and quickly receive meaningful analysis and professional reports.
